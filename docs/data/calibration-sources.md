# 보정 출처

합성 데이터의 분포는 아래 공개 통계를 참고해 정한다. 개별 점포의 실제 수치를 복제하지 않는다.

| 출처 | 쓰는 정보 | 용도 |
|---|---|---|
| 산업통상자원부 주요 유통업체 매출 동향(월간 보도자료) | 백화점 상품군별 매출 증감 | 카테고리 가중치, 계절성 |
| KOSIS 소매판매액지수(백화점) | 월별 지수 | 월별 추세 |
| 서울 열린데이터광장 상권분석서비스 추정매출(OA-22176) | 성별·연령·시간대·요일 매출 비중 | 고객 세그먼트, 시간 분포 |
| 서울 열린데이터광장 생활인구(OA-20314) | 시간대별 인구 | 시간대별 내점 강도 |
| DART 사업보고서 점포 현황 | 점포 영업면적 | 면적 규모 |

## 사용 원칙

- 보정값은 근사치이며 `catalog.py`와 생성기 설정에 둔다. 출처 링크와 함께 관리한다.
- 공공누리 등 각 출처의 이용 조건에 따라 출처를 표시한다.
- 원본 통계 파일은 저장소에 넣지 않는다. 필요한 경우 집계값만 기록한다.
